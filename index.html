勵馨家系圖生成器 - 使用說明

如何啟動程式

  • 離線使用：直接使用瀏覽器開啟此資料夾中的 index.html。
  • 安裝為 App：若已部署於網路 (HTTPS)，點擊網址列右側的「安裝」圖示，即可將其化身為桌面 App，並支援完全離線使用。
  • 建議使用 Chrome 或 Edge 瀏覽器。

基本操作

  • 新增人物：點擊「新增角色(N)」按鈕，選擇性別後自動放置。
  • 修改內容：使用「選取(V)」工具點擊人物或關係線。
  • 編輯人物：選取後在右側面板修改姓名、備註、是否死亡。
  • 建立關係：使用「連接(C)」工具，先點擊第一個人，再點擊第二個。
  • 生活圈：使用「生活圈(L)」工具點擊畫布繪製多邊形區域。

存檔邏輯 (重要)

  • 儲存 (Ctrl+S)：快速儲存至瀏覽器暫存。如果有連結檔案，則會直接同步。
  • 另存：將目前進度下載為 JSON 檔案，或是備份到電腦。
  • 同步存檔：先執行一次「另存」或「載入」建立連結後，按儲存就會直接更新檔案。

快速鍵

N: 新增角色 V: 選取 C: 連接 B: 範圍圈選 H: 同住圈選 L: 生活圈 Del: 刪除 Ctrl+Z: 復原 Ctrl+Y: 重做 Ctrl+S: 儲存 Esc: 取消
