勵馨家系圖生成器 - 使用說明

如何啟動程式

  • 線上版：以 Chrome 或 Edge 開啟專屬網址即可使用。
  • 離線臨床版：直接雙擊 geno/index.html（字型與程式資產皆在本機，不需網路，適合敏感個案與斷網環境；只有「匯出 Word」需要連網）。
  • 個案資料只存在瀏覽器暫存與您指定的 JSON 檔案，不會上傳任何伺服器。

基本操作

  • 新增成員：點擊「新增成員 (N)」選擇性別（或下方的寵物：貓 / 狗 / 鳥 / 魚 / 其他）後，畫布會顯示半透明格位預覽，點擊放置（按住 Alt 可精準落點，Esc 取消）。
  • 快速新增親屬：選取成員後，周圍出現「父母 / 手足 / 伴侶 / 兒子 / 女兒 / 懷孕 / 寵物」按鈕，一鍵新增並自動連線。寵物會掛在這個人（與伴侶）下面；懷孕、流產與寵物本身沒有寵物鈕。
  • 編輯成員：選取後在右側「屬性」修改姓名、年齡、性別、已過世、案主、生育結果（流產 / 人工流產）、備註、醫學標記；同父母的手足可設定多胞胎與同卵。填「出生年月」後年齡會自動計算（過世者再填死亡年月即為享年）。寵物可改種類，寵物不記年齡。
  • 調整文字位置：點成員姓名、關係線上的文字（結婚年份、說明）或同住圈名稱，會出現位置搖桿，可微調擺放；重大事件卡可直接拖曳。
  • 建立關係：使用「連接 (C)」先點第一個人再點第二個人，從清單選擇類型；親子線可選 親生 / 收養 / 寄養，伴侶類另有「前任關係」（虛線中間一條斜線）。
  • 不能建立的關係：家人之間（直系血親、手足、叔伯姑舅姨與姪甥、堂表兄弟姊妹等六親等內）不能建立伴侶關係；寵物不能有伴侶、不能當父母，寵物之間也不能有親子或收養關係（人養寵物時，寵物在子女那一端）。被擋下時會跳出說明。
  • 修改關係：用「選取 (V)」點關係線，線旁出現鉛筆（改類型）、⇄（對調方向）；右側面板也可直接改類型、子女線型與婚姻線走法。點選伴侶線或情感線時，線會「提起」加粗、其他內容漸漸變淡，方便看清楚這一條。
  • 婚姻線走法：選取婚姻線後，鉛筆旁有「自 / ㄇ / 一 / ㄩ」四個走法鈕；預設自動：同列淨空走直線、中間夾人時下折 ㄩ 避開。
  • 橫桿距離：選 ㄇ 或 ㄩ 走法後，面板可用 ＋／－ 調整橫桿與成員的距離，或直接在畫布上按住橫桿上下拖動；多段婚姻的天橋卡到上方成員時用這個調開。
  • 同住圈：用「範圍圈選 (B)」或 Shift 多選成員後按「同住圈 (H)」即建框；框可整體拖曳。選取框後右側可命名（顯示在框上）、用 ✕ 移出成員或從下拉加入成員；框線會自動繞開不在框內的人，不必手動微調位置。
  • 生活圈：用「生活圈 (L)」按住拖曳直接拉出橢圓，或逐點點頂點（Backspace 退回上一點）、雙擊或 Enter 完成。選取後可拖曳頂點改形狀、雙擊邊線新增頂點、Alt＋點頂點刪除；面板可命名、換色、設定名稱位置與說明。
  • 檢視：右側「檢視」頁籤可暫時隱藏姓名、年齡、備註、醫學標記、情感線、暴力與虐待線、同住圈、生活圈、重大事件（不刪資料，匯出圖片會遵循），並可設定「年齡基準日」看某個時間點的年齡；圖太擠時可把「排列間距」調成 1.25 或 1.5 倍。
  • 自動排列：依親子關係分輩分列、配偶相鄰、子女置中於父母下方、手足長→幼、多段婚姻依婚期排列（最近一段最靠近本人）；同住或有情感線的人會盡量靠近；寵物排在同組手足的最右邊。先預覽再「套用」或「取消」，套用後可 Ctrl+Z 復原。沒有親屬線的成員（包含只有情感線的）不會被移動。
  • 縮放：滾輪縮放；右鍵拖曳或空白鍵＋拖曳平移；左下角可「符合全圖」、重設 100%、「定位案主」（回到 100% 並置中案主，多位時輪流）。平板可雙指縮放與平移。縮得很小時姓名會自動放大、備註暫時隱藏（只影響螢幕，匯出不變）。

清單、重大事件與分享

  • 清單：右側「清單」頁籤列出全部人物與關係，可搜尋；點一下就跳到圖上並選取。
  • 重大事件：工具列「複製圖片」旁的「事件」：填年份與事件內容後按「加入事件」，清單每筆可「改」「刪」。事件依年份畫在家系圖下方的「重大事件」卡。
  • 畫面去識別化：右側面板上方的眼睛按鈕：螢幕上的姓名換成代號、備註／關係說明／事件不顯示；只改顯示，檔案不變，再按一次恢復。
  • 檢視模式：右側面板上方的螢幕按鈕：收起工具列與面板只留家系圖，適合投影或和個案一起看圖，按 Esc 離開。

存檔邏輯 (重要)

  • 標題列：顯示目前檔名；出現 ● 表示有變更尚未寫入檔案。
  • 儲存 (Ctrl+S)：若已連結檔案（曾「載入」或「另存」），直接寫回該檔；否則先存到瀏覽器暫存，並提醒您另存。
  • 另存：選擇位置與檔名，匯出 JSON 備份；之後 Ctrl+S 會直接更新這個檔案。
  • 載入：按「載入」會先列出最近載入的檔案，點一下即可重新載入並連結；也可「從電腦載入…」。載入大型檔案會自動符合全圖。
  • 共用電腦：「載入」視窗內的「清除本機暫存並關閉個案」會清掉瀏覽器暫存與最近檔案清單，回到空白畫布；不會刪除你另存的 JSON 檔。
  • 匯出圖片：PNG / JPEG / SVG / PDF / Word（Word 含家系圖、成員表與重大事件，需連網），可選是否含備註、圖例與解析度；勾「加上頁首」可印出標題、案號、日期、繪製者（標題／案號／繪製者會存進個案檔）；PDF 可選 A4 / A3 與直橫向。勾「去識別化」可把姓名換成代號（案主／男1／女1…）、隱藏備註與關係說明（年齡保留），適合交給督導、法院或教學使用，磁碟檔案不變。「複製圖片」可直接貼到 Word / LINE。
