# 勵馨家系圖生成器 (Genogram Tool)

這是一個專為社工與心理諮商師設計的輕量化、專業家系圖繪製工具。支援 PWA (Progressive Web App) 技術，可在桌面安裝並支援離線使用。

## 🚀 如何啟動程式

- **方法 A (雲端模式)**：直接訪問專屬網址 ([進入工具](https://goh2407-cyber.github.io/genogram/))。
- **方法 B (App 模式)**：使用 Chrome 或 Edge 開啟網址後，點擊網址列右側的「安裝」按鈕，即可將其轉為桌面 App 隨開即用。
- **方法 C (檔案模式)**：下載原始碼後，直接雙擊開啟 `index.html`。

## 🛠️ 基本繪圖操作

1. **新增人物**：
   - 點擊上方工具列的「新增角色 (N)」按鈕。
   - 選擇性別後，系統會自動放置角色至畫布。
2. **選取人物**：
   - 使用「選取(V)」工具點擊人物，右側會彈出屬性面板。
   - 可修改姓名、年齡、備註、生心理標記（如：藥物濫用、精神疾病）等資訊。
3. **建立關係**：
   - 使用「連接(C)」工具，先點擊第一個人物，再點擊第二個人物。
   - 點選建立後的連結線，可在右側選擇關係類型（如：結婚、離婚、衝突、親密等）。
4. **快速新增親屬**：
   - 選取一個人物後，畫面會顯示快速新增按鈕（父母、手足、伴侶、子女）。
   - 點擊即可一鍵新增相關角色並自動建立關係線。
5. **同住圈選 (Household)**：
   - 使用「範圍圈選(B)」工具框選多個人物，點擊「同住(H)」即可建立虛線圈選框。
6. **生活圈 (Life Circle)**：
   - 使用「生活圈(L)」工具，點擊畫布增加多邊形頂點。
   - 雙擊或按 Enter 完成繪製，按 Esc 取消。
   - 生活圈以半透明多邊形呈現，可用於標記不同生活場域。

## 💾 檔案管理與存檔邏輯

本程式提供兩種互補的儲存方式：

- **快速儲存 (Ctrl + S)**：
  - 優先嘗試直接更新已載入的檔案。
  - 若未載入檔案，則存入瀏覽器的「LocalStorage」暫存，下次開啟會自動回復。
- **另存新檔 (Save As)**：
  - 彈出視窗讓您選擇路徑與檔名，用於導出實體 JSON 備份檔。
- **載入 (Load)**：
  - 開啟先前的 JSON 存檔，載入後系統會自動「連結」該檔案，此後 Ctrl+S 將自動更新該實體檔。

## 🖼️ 圖片匯出

- 點擊工具列右側的「匯出」按鈕。
- 支援多種匯出格式：
  - **PNG**：點陣圖，適合分享。
  - **JPEG**：壓縮圖片，檔案較小。
  - **SVG**：向量圖，可無限放大。
  - **PDF**：文件格式，適合列印。
  - **JSON**：資料備份，可重新匯入編輯。

## ⚙️ 進階功能

- **自動排列**：點擊「自動排列」按鈕，系統會自動調整同輩人物的水平位置。
- **復原/重做**：支援多步驟的 Ctrl+Z 復原與 Ctrl+Y 重做。
- **縮放與平移**：
  - 滾輪放大縮小畫布。
  - 右鍵拖曳或空白鍵+拖曳，移動畫布視角。
- **拖曳移動**：選取人物後直接拖曳，可自由調整位置。

## 🔒 隱私與安全
- **本工具為 100% 本機執行**：您的所有個案資料、圖形皆儲存於您的瀏覽器或您指定的本地電腦路徑中。
- **無後端傳輸**：除了基本的 App 檔案載入外，資料不會上傳至任何伺服器。
