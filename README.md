# 勵馨家系圖生成器 (Genogram Tool)

這是一個專為社工與心理諮商師設計的輕量化、專業家系圖繪製工具。

## 📌 目前版本與使用情境

- **線上／開發版**：根目錄 (`index.html`, `js/`, `css/`)；會向 Google Fonts、cdnjs 與 unpkg 載入字型或程式資產。
- **離線臨床包**：`geno/`；字型、jsPDF 與 dagre 均為本地檔案，適合敏感個案及無網路環境。
- **驗證副本**：`refactor/app/`；與根目錄功能碼同步，不作為獨立部署政策來源。
- **個案資料**：三個版本都只在瀏覽器與使用者指定檔案中處理，不會主動上傳至後端。

## 🚀 如何啟動程式

- **方法 A (雲端模式)**：直接訪問專屬網址 ([進入工具](https://goh2407-cyber.github.io/genogram/))。
- **方法 B (檔案模式)**：下載原始碼後，直接雙擊開啟 `index.html`（可用於本機編輯與測試）。
- **方法 C (離線臨床模式)**：完整保留 `geno/` 目錄，直接雙擊 `geno/index.html`；此版本不需網路資產。

## 🛠️ 基本繪圖操作

1. **新增人物**：
   - 點擊上方工具列的「新增角色 (N)」按鈕。
   - 選擇性別後，系統會自動放置角色至畫布。
2. **選取人物**：
   - 使用「選取(V)」工具點擊人物，右側會彈出屬性面板。
   - 可修改姓名、年齡、備註、生心理標記（如：藥物濫用、精神疾病）等資訊。
   - 填「出生年月」後年齡自動計算（過世者填死亡年月即為享年）；右側「檢視」頁籤可設定年齡基準日。
3. **建立關係**：
   - 使用「連接(C)」工具，先點擊第一個人物，再點擊第二個人物。
   - 親子線可選 **親生 / 收養 / 寄養**（虛線與點線遵循 McGoldrick 標準）；對話框最上方會列出「最近使用」的類型。
   - 用「選取(V)」點關係線，線旁出現鉛筆（改類型）與 ⇄（對調方向）；右側面板也可直接改類型、子女線型與婚姻線走法。
   - 婚姻線走法：選取後鉛筆旁有「自 / ㄇ / 一 / ㄩ」四個走法鈕；預設自動（同列淨空直線、夾人時 ㄩ 下折避開）。
   - 點選連結線，可在右側屬性面板輸入「時間/說明」，支援多行顯示。
4. **快速新增親屬**：
   - 選取一個人物後，畫面會顯示快速新增按鈕（父母、手足、伴侶、兒子、女兒、懷孕）；按鈕大小不隨縮放改變。
   - 點擊即可一鍵新增相關角色並自動建立關係線；放置前有半透明格位預覽，按住 Alt 可精準落點。
   - 同父母的手足可在屬性面板設定多胞胎，並標記同卵（畫連接橫桿）；「生育結果」可標記流產（●）或人工流產（X）。
5. **同住圈選 (Household)**：
   - 使用「範圍圈選(B)」工具框選多個人物，點擊「同住(H)」即可建立虛線圈選框；已用 Shift 多選好人時直接按 H 即建框。
   - 選取框後可命名（顯示在框上）、用 ✕ 移出成員或從下拉加入成員；框線會自動繞開不在框內的人；圖例列出「同住框」樣本。
6. **生活圈 (Life Circle)**：
   - 使用「生活圈(L)」工具：按住拖曳直接拉出橢圓，或點擊畫布逐點增加頂點（Backspace 退回上一點）。
   - 雙擊或按 Enter 完成繪製，按 Esc 取消。
   - 選取後可拖曳頂點改形狀、雙擊邊線新增頂點、Alt＋點頂點刪除；面板可設定名稱位置（頂部／中央／底部）與說明。
   - 生活圈以半透明多邊形呈現，可用於標記不同生活場域。
7. **其他实用工具**：
   - **複製圖片**：點擊工具列的「複製圖片」圖示，直接將目前畫面複製到剪貼簿。
   - **清空畫布**：點擊紅色垃圾桶圖示可清空畫布所有內容。

## 💾 檔案管理與存檔邏輯

本程式提供兩種互補的儲存方式：

- **標題列**：顯示目前檔名；出現桃紅 ● 表示有變更尚未寫入檔案（滑過可看提示）。
- **快速儲存 (Ctrl + S)**：
  - 優先嘗試直接更新已載入的檔案。
  - 若未載入檔案，則存入瀏覽器的「LocalStorage」暫存，下次開啟會自動回復。
- **另存新檔 (Save As)**：
  - 彈出視窗讓您選擇路徑與檔名，用於導出實體 JSON 備份檔。
- **載入 (Load)**：
  - 按「載入」會先列出最近開過的檔案（記在這台電腦的瀏覽器裡），點一下即可重開並連結；也可「瀏覽檔案…」。
  - 開啟先前的 JSON 存檔後系統會自動「連結」該檔案，此後 Ctrl+S 將自動更新該實體檔。
  - 共用電腦：同一視窗有「清除本機暫存並關閉個案」，會清掉瀏覽器暫存與最近檔案清單，不刪除你另存的 JSON。

## 🗂️ 專案結構（目前）

- `index.html`, `js/`, `css/`：線上／開發版程式碼
- `geno/`：包含本地字型與 vendor 資產的離線臨床包
- `refactor/app/`：與根目錄同步的驗證副本
- `refactor/`：測試、效能基準與設計文件
- `genogram_*.json`：資料檔（不納入程式碼版控）

## 🖼️ 圖片匯出

- 點擊工具列右側的「匯出」按鈕。
- 可勾「加上頁首」印出標題、案號、日期、繪製者；標題／案號／繪製者會存進個案 JSON（`meta`），日期預設今天。PDF 可選 A4 / A3 與直橫向。
- 可勾「去識別化」：姓名→代號（案主／男1／女1…）、年齡→年齡帶（十年一段）、隱藏備註與關係說明、頁首標題改為中性；只影響輸出，檔案與畫面不變。適合交督導、法院或教學。
- 支援多種匯出格式：
  - **PNG**：點陣圖，適合分享。
  - **JPEG**：壓縮圖片，檔案較小。
  - **SVG**：向量圖，可無限放大。
  - **PDF**：文件格式，適合列印。
  - **JSON**：資料備份，可重新匯入編輯。

## ⚙️ 進階功能

- **自動排列**：點擊「自動排列」按鈕，系統會自動調整同輩人物的水平位置。
- **復原/重做**：支援多步驟的 Ctrl+Z 復原與 Ctrl+Y 重做。
- **縮放與平移**：
  - 滾輪放大縮小畫布。
  - 右鍵拖曳或空白鍵+拖曳，移動畫布視角；平板可雙指縮放與平移。
  - 左下角「定位案主」回到 100% 並置中案主（多位時輪流）。縮得很小時姓名自動放大、備註暫時隱藏（只影響螢幕，匯出不變）。
- **符合全圖**：縮放控制列的四角圖示可手動符合全圖；大型 JSON 載入後會自動縮放，小型圖維持 100%。
- **畫布檢視**：右側「檢視」頁籤可暫時隱藏姓名、年齡、備註、醫學標記、一般情感線、同住框與生活圈；不會刪除資料。
- **匯出一致性**：PNG/JPEG/SVG/PDF 與複製圖片遵循目前檢視，JSON 備份仍保留完整個案資料。
- **拖曳移動**：選取人物後直接拖曳，可自由調整位置。

## 🔒 隱私與安全

- 個案資料不會由本工具主動上傳；儲存位置是瀏覽器 LocalStorage 或使用者指定的本地 JSON。
- 根目錄版本會連線取得第三方字型／程式資產，因此網路服務可看見一般資產請求，但請求不包含家系圖個案內容。
- 敏感個案、內網或斷網作業請優先使用 `geno/index.html`；離線驗證要求零 HTTP/HTTPS 請求。
- Service Worker 已停用；離線能力來自 `geno/` 內完整的本地資產，不依賴瀏覽器快取。
