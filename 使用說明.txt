=========================================
      家系圖繪製工具 - 使用說明文件
=========================================

這是一份簡易的操作指南，幫助您快速上手家系圖繪製工具。

-----------------------------------------
〇、 如何啟動程式
-----------------------------------------
- 方法 A (檔案模式)：直接使用瀏覽器雙擊開啟 「index.html」 即可啟動工具。
- 方法 B (App 模式)：若您已將工具放上網路 (HTTPS 網址)，使用 Chrome 開啟後點擊網址列右側的「安裝」按鈕，即可將其轉為桌面 App 隨開即用，且支援斷網使用。

-----------------------------------------
一、 基本繪圖操作
-----------------------------------------
1. 新增人物：
   - 點擊上方工具列的「男(M)」或「女(F)」按鈕。
   - 在畫布上的任何位置點擊左鍵，即可新增。
2. 選取人物：
   - 使用「選取(V)」工具點擊人物。
   - 選中後，右側會彈出屬性面板，可修改姓名、備註、是否死亡等資訊。
3. 建立關係：
   - 使用「連接(C)」工具。
   - 先點擊第一個人物品，再點擊第二個人物。
   - 點選建立後的連結線，可在右側選擇關係類型（例如：配偶、衝突、親密等）。
4. 同住圈選 (Household)：
   - 使用「範圍圈選(B)」在畫布上框選多個人物。
   - 點擊「同住(H)」工具，系統會自動在選中人物周圍建立虛線圈選框。

-----------------------------------------
二、 檔案管理（重要：存檔邏輯）
-----------------------------------------
本程式提供兩種互補的儲存方式，確保您的工作不遺失：

1. 儲存 (Ctrl + S)：
   - 這是一個「快速儲存」功能。
   - 程式會優先嘗試直接寫入檔案。
   - 如果您剛啟動程式或重新整理過，系統會先存入「瀏覽器暫存」(LocalStorage)。
   - 提示：如果您想要直接寫入電腦裡的 JSON 檔，請先執行一次「載入」或「另存」。

2. 另存 (Save As)：
   - 這是專門用來「導出檔案」或「備份」的功能。
   - 點擊後會彈出視窗，讓您選擇電腦中的存檔路徑與檔名。
   - 建議在收班或完成一個階段工作時執行一次另存，保留實體備份。

3. 載入 (Load)：
   - 點擊「載入」可開啟先前儲存過的 JSON 檔案。
   - 載入後，系統會自動「連結」該檔案，此後按 Ctrl+S 就會直接自動更新該檔案。

-----------------------------------------
三、 圖片匯出
-----------------------------------------
- 點擊工具列右側的「匯出」按鈕。
- 系統會將目前的畫布（包含圖例說明）轉換為 PNG 圖片格式並下載。

-----------------------------------------
四、 快速鍵 (Shortcuts)
-----------------------------------------
- [V]：切換為選取工具
- [M]：切換為新增男性
- [F]：切換為新增女性
- [C]：切換為連接關係工具
- [B]：切換為範圍圈選工具
- [H]：切換為同住圈選工具
- [Del]：刪除選中的人物或關係
- [Ctrl + Z]：復原上一個步驟
- [Ctrl + Y]：重做
- [Ctrl + S]：快速儲存進度
- [滑鼠滾輪]：放大/縮小畫布
- [空白鍵 + 拖曳] 或 [右鍵拖曳]：移動(Pan)畫布

-----------------------------------------
五、 注意事項
-----------------------------------------
- 本工具會自動記憶您的縮放比例與畫面中心點。下次開啟時會盡量回復到您離開時的視角。
- 為了保護您的資料，建議定期點擊「另存」將進度備份到電腦中的實體檔案裡。
