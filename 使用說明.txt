=========================================
   勵馨家系圖生成器 - 使用說明文件
=========================================

這是一份簡易的操作指南，幫助您快速上手家系圖繪製工具。
（2026-09 更新：補上收養/寄養線、雙胞胎、生育結果、婚姻線走法、檢視頁籤、標題列檔名等新功能）

-----------------------------------------
〇、 如何啟動程式
-----------------------------------------
- 方法 A (線上版)：以 Chrome 或 Edge 開啟 https://goh2407-cyber.github.io/genogram/
- 方法 B (檔案模式)：直接用瀏覽器雙擊開啟「index.html」。
- 方法 C (離線臨床版)：完整保留 geno 資料夾，雙擊「geno/index.html」。
  字型與程式資產都在本機，全程零網路請求，適合敏感個案與斷網環境。
- 個案資料只存在瀏覽器暫存與您指定的 JSON 檔案，不會上傳任何伺服器。

-----------------------------------------
一、 基本繪圖操作
-----------------------------------------
1. 新增人物：
   - 點擊上方工具列的「新增角色 (N)」，選擇性別（含多元性別選項）。
   - 畫布會出現半透明的格位預覽，點擊即放置；按住 Alt 可精準落點；Esc 取消。

2. 選取人物：
   - 使用「選取 (V)」工具點擊人物，右側「屬性」面板可修改：
     姓名、年齡、性別、已過世、案主/關注對象、備註（顯示 2 行）。
   - 出生年月：填了之後年齡會自動計算，不用每年手動改；過世者再填「死亡年月」即顯示享年。
     右側「檢視」頁籤可設定「年齡基準日」，看某個時間點（例如事件當時）每個人幾歲。
   - 生育結果：可標記「流產（自然）」= 小實心圓點、「人工流產」= X。
   - 醫學與狀態：生理/心理疾病（左半部）、酒精/藥物濫用（下半部）、吸菸 S、肥胖 O、語言障礙 L。
   - 多胞胎：同父母的手足可設定為多胞胎，並勾選「同卵」（畫連接橫桿）。
   - 點人物的「姓名文字」會出現位置搖桿，可拖曳微調姓名與備註的擺放位置。

3. 快速新增親屬：
   - 選取一個人物後，周圍出現「父母 / 手足 / 伴侶 / 兒子 / 女兒 / 懷孕」按鈕。
   - 點擊即一鍵新增並自動建立關係線；按鈕大小不會隨畫布縮放改變，縮很小也點得到。

4. 建立關係：
   - 使用「連接 (C)」工具，先點第一個人，再點第二個人，從清單選擇類型。
   - 親子線可選「親生（實線）/ 收養（虛線）/ 寄養（點線）」。
   - 清單最上方會列出您「最近使用」的類型，常用的不必再往下找。

5. 修改關係：
   - 用「選取 (V)」點關係線，線旁出現：鉛筆（改類型）、⇄（對調方向，親子與虐待線用）。
   - 右側面板也可直接按「變更類型…」，或切換子女線型（親生/收養/寄養）。
   - 婚姻線走法：選取婚姻線後，鉛筆旁有「自 / ㄇ / 一 / ㄩ」四個走法鈕（面板也有）。
     預設「自動」：同列淨空走直線、中間夾著其他人時往下折 ㄩ 避開、同側多段婚姻架 ㄇ 天橋。
     ㄇ 上折只在該人上方沒有父母線時適合使用。
   - 「時間/說明」欄位可輸入多行，會顯示在線上（例如：結婚 2010 / 離婚 2020）。

6. 同住框 (Household)：
   - 使用「範圍圈選 (B)」框選多位成員，再按「同住 (H)」建立虛線框。
   - 框可整體拖曳（成員一起移動），可加備註。

7. 生活圈 (Life Circle)：
   - 使用「生活圈 (L)」在畫布點擊增加頂點，雙擊或 Enter 完成，Esc 取消。
   - 可命名（顯示於圈上）、換色、拖曳；用於標記學校、教會、社區據點等生活場域。

8. 檢視頁籤：
   - 右側「檢視」可暫時隱藏：姓名、年齡、備註與關係說明、醫學標記、情感關係線、同住框、生活圈。
   - 只是隱藏、不會刪除資料；匯出圖片會遵循目前的檢視設定（JSON 備份仍是完整資料）。

9. 其他工具：
   - 複製圖片：把目前家系圖複製到剪貼簿，可直接貼到 Word / LINE。
   - 自動排列：依輩分整理水平位置，先預覽再決定套用或取消。
   - 清空畫布：紅色垃圾桶（與「刪除」之間有分隔線，避免誤按），會先確認，可復原。

-----------------------------------------
二、 檔案管理（重要：存檔邏輯）
-----------------------------------------
0. 標題列：
   - 左上方顯示目前檔名（未連結檔案時為「未命名家系圖」）。
   - 出現桃紅色「●」表示有變更尚未寫入檔案；滑鼠移過去可看提示。

1. 儲存 (Ctrl + S)：
   - 若已連結檔案（曾「載入」或「另存」），會直接寫回該檔案，● 消失。
   - 若尚未連結檔案，會先存到瀏覽器暫存，並提醒您「另存」建立實體檔。

2. 另存 (Save As)：
   - 彈出視窗選擇路徑與檔名，匯出 JSON 備份檔；之後 Ctrl+S 會直接更新這個檔案。
   - 建議收班或完成一個階段時另存一次，保留實體備份。

3. 載入 (Load)：
   - 按「載入」會先跳出「開啟檔案」視窗，列出最近開過的檔案，點一下即重開並連結。
   - 也可按「瀏覽檔案…」選其他 JSON。載入後 Ctrl+S 直接更新該檔。
   - 大型檔案載入後會自動「符合全圖」，小圖維持 100%。

4. 共用電腦離開前：
   - 「開啟檔案」視窗內有「清除本機暫存並關閉個案」，會清掉瀏覽器暫存、最近檔案清單、
     畫布內容與復原紀錄，回到空白畫布。不會刪除你已另存到電腦裡的 JSON 檔。

-----------------------------------------
三、 圖片匯出（多格式支援）
-----------------------------------------
- 點擊工具列右側的「匯出」。
- 可選：是否顯示備註、是否顯示關係圖例、解析度（2x / 1x）。
- 加上頁首：勾選後可填標題、案號、繪製者（會存進這份個案的 JSON）與日期（預設今天），
  匯出的圖片／PDF 最上方會印出來，方便歸檔。「複製圖片」不加頁首。
- PDF 紙張：可選 A4 / A3，方向預設依圖片比例自動，也可指定橫向或直向。
- 格式：
  - PNG：點陣圖，適合分享。
  - JPEG：壓縮圖片，檔案較小。
  - SVG：向量圖，可無限放大，適合印刷。
  - PDF：文件格式，適合列印或存檔。
  - JSON：資料備份，可重新匯入編輯。

-----------------------------------------
四、 進階功能
-----------------------------------------
1. 復原/重做：Ctrl+Z / Ctrl+Y，支援多步驟。
2. 縮放與平移：
   - 滾輪縮放；右鍵拖曳或空白鍵+拖曳平移。
   - 左下角縮放列：放大、縮小、符合全圖、重設 100%。
3. 拖曳吸附：
   - 拖曳人物時會出現桃紅色輔助線，自動對齊他人、父母中點、同列等距與輩分列。
   - 按住 Alt 拖曳可關閉吸附、精準放置。
4. 多選：Shift + 點擊可多選人物；「範圍圈選 (B)」可框選。

-----------------------------------------
六、 快速鍵 (Shortcuts)
-----------------------------------------
- [N]：新增角色
- [V]：選取工具
- [C]：連接關係工具
- [B]：範圍圈選工具
- [H]：同住圈選
- [L]：生活圈工具
- [Del]：刪除選中的物件
- [Esc]：取消操作或關閉對話框
- [Ctrl + Z] / [Ctrl + Y]：復原 / 重做
- [Ctrl + S]：快速儲存
- [Shift + 點擊]：多選人物
- [Alt + 放置/拖曳]：精準落點（不吸附）
- [滑鼠滾輪]：放大/縮小
- [右鍵拖曳] 或 [空白鍵 + 拖曳]：移動 (Pan) 畫布

-----------------------------------------
七、 注意事項
-----------------------------------------
- 本工具會記憶縮放比例與畫面位置，下次開啟盡量回復到離開時的視角。
- 為保護資料，建議定期「另存」到電腦中的實體檔案；標題列出現 ● 就是提醒。
- 本工具 100% 在您的電腦上執行，個案資料不會上傳至任何伺服器。
- 敏感個案、共用電腦或斷網作業，請優先使用離線臨床版 geno/index.html。
