=========================================
   勵馨家系圖生成器 - 使用說明文件
=========================================

這是一份簡易的操作指南，幫助您快速上手家系圖繪製工具。

-----------------------------------------
〇、 如何啟動程式
-----------------------------------------
- 方法 A (雲端模式)：直接訪問網址 https://goh2407-cyber.github.io/genogram/
- 方法 B (檔案模式)：直接使用瀏覽器雙擊開啟 「index.html」 即可啟動工具。
- 方法 C (App 模式)：若您已將工具放上網路 (HTTPS 網址)，使用 Chrome 開啟後點擊網址列右側的「安裝」按鈕，即可將其轉為桌面 App 隨開即用，且支援斷網使用。

-----------------------------------------
一、 基本繪圖操作
-----------------------------------------
1. 新增人物：
   - 點擊上方工具列的「新增角色 (N)」按鈕。
   - 選擇性別後，系統會自動放置角色至畫布。

2. 選取人物：
   - 使用「選取(V)」工具點擊人物。
   - 選中後，右側會彈出屬性面板，可修改姓名、備註、是否死亡等資訊。
   - 支援設定生心理標記（如：藥物濫用、精神疾病、酒精議題等）。

3. 建立關係：
   - 使用「連接(C)」工具。
   - 先點擊第一個人物，再點擊第二個人物。
   - 系統會彈出關係選擇對話框，可選擇各種關係類型。

4. 快速新增親屬（新功能）：
   - 選取一個人物後，畫面會顯示快速新增按鈕。
   - 提供父母、手足、伴侶、子女、懷孕等選項。
   - 點擊即可一鍵新增相關角色並自動建立關係線。

5. 同住圈選 (Household)：
   - 使用「範圍圈選(B)」在畫布上框選多個人物。
   - 點擊「同住(H)」工具，系統會自動在選中人物周圍建立虛線圈選框。

6. 生活圈 (Life Circle)（新功能）：
   - 使用「生活圈(L)」工具。
   - 在畫布上點擊增加多邊形頂點。
   - 雙擊或按 Enter 完成繪製，按 Esc 取消。
   - 生活圈會以半透明多邊形呈現，可用於標記不同生活場域。
   - 可選取生活圈後進行拖曳移動。

-----------------------------------------
二、 檔案管理（重要：存檔邏輯）
-----------------------------------------
本程式提供兩種互補的儲存方式，確保您的工作不遺失：

1. 儲存 (Ctrl + S)：
   - 這是一個「快速儲存」功能。
   - 程式會優先嘗試直接寫入檔案。
   - 如果您剛啟動程式或重新整理過，系統會先存入「瀏覽器暫存」(LocalStorage)。
   - 提示：如果您想要直接寫入電腦裡的 JSON 檔，請先執行一次「載入」或「另存」。

2. 另存 (Save As)：
   - 這是專門用來「導出檔案」或「備份」的功能。
   - 點擊後會彈出視窗，讓您選擇電腦中的存檔路徑與檔名。
   - 建議在收班或完成一個階段工作時執行一次另存，保留實體備份。

3. 載入 (Load)：
   - 點擊「載入」可開啟先前儲存過的 JSON 檔案。
   - 載入後，系統會自動「連結」該檔案，此後按 Ctrl+S 就會直接自動更新該檔案。

-----------------------------------------
三、 圖片匯出（多格式支援）
-----------------------------------------
- 點擊工具列右側的「匯出」按鈕。
- 系統會彈出格式選擇對話框，支援：
  - PNG：點陣圖，適合分享。
  - JPEG：壓縮圖片，檔案較小。
  - SVG：向量圖，可無限放大，適合印刷。
  - PDF：文件格式，適合列印或存檔。
  - JSON：資料備份，可重新匯入編輯。

-----------------------------------------
四、 進階功能
-----------------------------------------
1. 自動排列：
   - 點擊「自動排列」按鈕，系統會自動調整同輩人物的水平位置。
   - 幫助快速整理畫面，避免人物重疊。

2. 復原/重做：
   - Ctrl+Z：復原上一步操作。
   - Ctrl+Y：重做已復原的操作。
   - 支援多步驟歷史紀錄。

3. 縮放與平移：
   - 滾輪：放大/縮小畫布。
   - 右鍵拖曳或空白鍵+拖曳：移動畫布視角。
   - 可使用右下角的縮放按鈕精確控制。

-----------------------------------------
五、 關係類型說明
-----------------------------------------
工具支援豐富的關係類型：

【家庭關係】
  結婚、訂婚、同居、法律同居、事實分居、法律分居、離婚、喪偶、外遇

【情感關係（正向）】
  和諧、愛、熱戀、親密/友誼、非常親密、崇拜、關注

【情感關係（負向）】
  冷漠、疏離、斷絕、衝突、仇恨、敵對、遠距敵對、親密敵對、衝突又親密

【虐待/暴力】
  暴力、虐待、身體虐待、情緒虐待、性虐待、忽視、操控、控制

-----------------------------------------
六、 快速鍵 (Shortcuts)
-----------------------------------------
- [V]：切換為選取工具
- [N]：新增角色
- [C]：切換為連接關係工具
- [B]：切換為範圍圈選工具
- [H]：切換為同住圈選工具
- [L]：切換為生活圈工具
- [Del]：刪除選中的人物或關係
- [Esc]：取消操作或關閉對話框
- [Ctrl + Z]：復原上一個步驟
- [Ctrl + Y]：重做
- [Ctrl + S]：快速儲存進度
- [滑鼠滾輪]：放大/縮小畫布
- [空白鍵 + 拖曳] 或 [右鍵拖曳]：移動(Pan)畫布

-----------------------------------------
七、 注意事項
-----------------------------------------
- 本工具會自動記憶您的縮放比例與畫面中心點。下次開啟時會盡量回復到您離開時的視角。
- 為了保護您的資料，建議定期點擊「另存」將進度備份到電腦中的實體檔案裡。
- 本工具為 100% 本機執行，您的個案資料不會上傳至任何伺服器。
