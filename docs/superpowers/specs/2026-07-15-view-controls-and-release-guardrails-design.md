# 家系圖檢視控制與發布護欄設計

日期：2026-07-15
狀態：已於對話中核准，待書面複核

## 1. 目標

本輪工作解決 2026-07-15 稽核中最明確的發布與易用性缺口：

1. 把右側「檢視」分頁從占位內容改成可用的顯示層控制。
2. 讓大型家系圖在開檔後不會因固定 100% 縮放而看似遺失人物。
3. 修正新增人物文案、長駐狀態提示與 favicon 404。
4. 收尾 Golden baseline、三副本位元一致性及 root／`geno` 部署定位。

成功時，預設畫面及臨床符號語意維持不變；使用者可暫時降低複雜圖面的資訊密度，且螢幕、圖片匯出與 PDF 匯出一致。

## 2. 範圍

### 2.1 本輪包含

- 七個顯示層開關：姓名、年齡、備註、醫學標記、情感關係線、同住框、生活圈。
- 手動「符合全圖」及開啟 JSON 後的條件式自動符合全圖。
- PNG、JPEG、SVG、PDF 與複製圖片遵循目前檢視設定。
- 一般新增人物文案、狀態提示淡出與 favicon 修正。
- 指定 Golden 圖逐張核准更新、三副本 raw MD5 驗證及部署說明。
- 更新稽核報告與測試證據。

### 2.2 本輪不包含

- 焦點模式、語意縮放、導覽縮圖。
- 修改家庭、婚姻、親子或單親安全走線演算法。
- 修改臨床符號定義、顏色或關係線語意。
- 將檢視設定寫入個案 JSON、瀏覽器自動儲存或 undo/redo history。
- 將 root 改為全本地依賴，或將 `geno` 改回 CDN。

## 3. 集中式檢視狀態

`App` 保存單一工作階段狀態，畫布與匯出共用它：

```js
this.viewOptions = {
    showNames: true,
    showAges: true,
    showNotes: true,
    showMedical: true,
    showEmotionalRelationships: true,
    showHouseholds: true,
    showLifeCircles: true
};
```

所有欄位僅接受布林值；缺少或無效值一律回到 `true`。設定不修改 `Person`、`Relationship`、household 或 life circle 資料，也不參與儲存、載入、歷史快照及親屬推論。

右側「檢視」分頁以七個可鍵盤操作的 checkbox 呈現，預設全部勾選。切換後立即重繪，但不改變縮放、平移或人物座標。設定在重新整理後回復預設，避免把臨時簡化視圖誤認為個案資料的一部分。

## 4. 顯示規則

### 4.1 人物層

- `showNames=false`：不畫姓名。
- `showAges=false`：不畫人物符號中央的年齡。
- `showNotes=false`：不畫人物備註，也不畫關係日期／說明。
- 姓名關閉但備註開啟時，備註從人物符號下方第一行開始，不保留空白姓名行。
- 顯示切換只影響繪製；家庭走線幾何不因標籤開關重新規劃，避免切換時整張圖的線路跳動。

`showMedical=false` 只隱藏 `person.medical` 所代表的醫療填色、中心符號與 S／O／L 標籤。下列臨床核心符號永遠保留：

- 性別形狀及淡性別底色
- 案主標示
- 死亡 X
- 流產／人工流產及懷孕符號
- 性傾向及跨性別符號
- 選取、連線與搜尋狀態環

### 4.2 關係及群組層

- `showEmotionalRelationships=false` 只排除 `emotional` category；family、marriage、abuse／violence 等類別照常顯示。
- 情感線關閉時，畫布命中測試、選取、高亮與編輯不再命中被隱藏的情感關係；若切換前正選取情感關係，切換時清除該選取。
- 情感線關閉時，匯出圖例移除正向及負向情感關係區塊；虐待／暴力區塊保留。
- `showHouseholds=false` 與 `showLifeCircles=false` 同時排除繪製、命中測試與內容邊界計算；資料仍完整保留。
- 使用者啟動同住框或生活圈建立工具時，若對應層已關閉，應先自動重新開啟並同步 checkbox，避免建立不可見物件。
- 使用者完成新的情感關係時，若情感層已關閉，應重新開啟該層，讓建立結果立即可見。

## 5. 匯出一致性

PNG、JPEG、SVG、PDF 與「複製圖片」必須傳入同一份正規化後的 `viewOptions`。JSON 匯出不套用顯示過濾，永遠保留完整資料。

現有匯出視窗的「顯示備註」仍保留，最終規則為：

```text
effectiveShowNotes = viewOptions.showNotes && exportDialog.showNotes
```

因此匯出視窗可以再減少備註，但不能把「檢視」分頁已關閉的備註重新打開。姓名、年齡、醫學標記、情感線、同住框與生活圈則直接遵循 `viewOptions`。

匯出邊界只包含目前會畫出的層；關閉生活圈或同住框後，不得因隱藏物件仍在遠處而產生大片空白。匯出期間不得暫時改寫人物或關係物件，避免例外發生時污染資料。

## 6. 符合全圖

新增獨立的「符合全圖」控制，保留既有「重置 100%」：

- 「重置 100%」：比例固定為 1，將內容中心移到畫布中心。
- 「符合全圖」：以目前可見層計算內容邊界；沿用邊界函式既有的 50 世界座標單位 margin，並在畫布四邊各保留 24 CSS px。比例取 `min(1, (canvasWidth - 48) / bounds.width, (canvasHeight - 48) / bounds.height)`。
- 比例仍受現有 25% 下限限制；若 25% 仍不能完整容納，維持 25%、置中內容並顯示清楚的資訊提示。
- 空畫布按「符合全圖」時回到 100% 與零偏移，不報錯。

`loadData()` 完成資料正規化及畫布尺寸確認後執行條件式自動符合：

- 內容在 100% 下能完整容納：使用 100% 並置中。
- 內容超出可視區：自動符合全圖。
- 恢復瀏覽器自動儲存：保留已儲存的比例與偏移，不自動符合。
- 切換顯示層、收合 Inspector 或調整視窗大小：只重繪，不自動移動畫面；使用者可手動按符合全圖。

右下角按鈕具備可辨識的向量圖示、繁中 title 與 `aria-label`，縮放百分比在自動或手動操作後立即更新。

## 7. 小型 UX 修正

### 7.1 新增人物文案

一般工具列「新增角色」仍使用既有 parent generation 作為初始格位，但狀態文案改為「選擇新增人物的性別」。快速新增父母、伴侶或子女維持各自的親屬文案。

### 7.2 狀態提示生命週期

`updateStatus` 增加可取消的單一計時器：

- 「就緒」與被明確標記為被動的 info／success 訊息在 3500ms 後淡出。
- 被明確標記為被動的 warning／error 訊息在 6000ms 後淡出。
- 放置、連線、圈選、生活圈繪製等進行中提示不自動消失。
- 每次顯示新訊息前取消上一個計時器；舊計時器不得關閉後來的新訊息。
- 主動清除狀態時同步取消計時器。

現有正在進行的操作以預設常駐為原則，只在確認屬於完成通知的呼叫點啟用淡出，降低大範圍文案分類造成的回歸風險。

### 7.3 Favicon

root、`geno/` 與 `refactor/app/` 的 `<head>` 指向各自現有的 `icon-512.png`，不新增外部請求。一般載入不得再出現 `/favicon.ico` 404。

## 8. 部署定位與三副本規則

- root：需網路的開發／公開版，可使用 Google Fonts、cdnjs jsPDF 與 unpkg dagre。
- `geno/`：零外部請求的離線臨床包；處理敏感個案或無網路環境時優先使用。
- `refactor/app/`：重構與驗證副本，不作為獨立部署政策來源。

本輪只補足文件與驗證，不互換 root 與 `geno` 的依賴策略。文件須明示：root 的第三方請求只載入程式／字型資產，不會主動上傳個案資料，但敏感情境仍建議使用 `geno`。

每輪同步後：

1. root、`geno/`、`refactor/app/` 的 JS 與 CSS 必須做位元級複製並通過 raw MD5。
2. root 與 `refactor/app/index.html` 必須一致。
3. `geno/index.html` 保留本地字型及 vendor 路徑差異，但其功能性標記與控制項必須同步。
4. 新增自動驗證，讓 EOL 差異也會造成明確失敗。

## 9. Golden 基準

先前 16 張 Golden 中，03、08、10、12、13、15、16 的差異已確認只來自 Golden 建立後加入的家庭／親子安全走線。更新時只可替換這七張已核准 current 圖，不得使用整批 baseline 覆寫。

更新後重跑全部 16 張，要求 16/16 完全通過。若本輪預設全開的檢視狀態造成任何其他 fixture 差異，視為回歸，不得直接接受。

## 10. 測試與驗收

### 10.1 新增回歸測試

測試涵蓋：

- 七個 checkbox 預設全開、可用鍵盤切換並立即重繪。
- 各層在螢幕與匯出中的顯示一致。
- 隱藏物件不再被畫布命中；重新建立對應物件時自動開層。
- 姓名關閉且備註開啟時沒有空白姓名行。
- 醫學標記關閉時核心臨床符號仍存在。
- 情感線關閉時其他關係與虐待／暴力線仍存在，匯出圖例同步縮減。
- 小型資料開檔維持 100%；大型資料自動縮小並完整置中；手動符合與重置 100% 可互相切換。
- 25% 仍無法容納時顯示提示；空畫布符合全圖安全回復預設。
- 一般新增人物文案正確。
- 被動訊息淡出、操作訊息常駐、舊計時器不會關閉新訊息。
- favicon 不再產生 404。

### 10.2 既有護欄

- 15 支既有 `verify_*.js` 全數通過。
- 視覺煙霧測試零 console error。
- Golden 16/16 通過。
- 200 人效能基準不得出現明顯退步；顯示層預設全開時結果應維持同量級。
- root／`geno`／`refactor/app` JS/CSS raw MD5 驗證通過，`geno` 零外部請求驗證通過。
