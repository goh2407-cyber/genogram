# 建立第二組父母時的輕量子女彈開設計

日期：2026-07-15
分支：`codex/view-controls-release-hardening`

## 問題與根因

兩位同輩伴侶距離只有一個系統格距時，先為其中一人建立父母，再為另一人
建立父母，第二組父母若仍以固定一格的配對寬度置中於子女正上方，內側兩位
父母會占用同一格。現有放置器為了不重疊，會把整組新父母向伴侶外側平移
一格。

人物沒有重疊、親屬方向也正確，但新父母的婚姻線不再位於子女正上方。
`GenogramCanvas._getFamilySource()` 會把親子線起點夾到婚姻線最靠近子女的
端點，正式圖面因此出現從內側父母旁邊落下、再大幅水平折向子女的 L 形線。

## 已評估方案

1. **只改親子線起點**：改從婚姻線中點落下。改動最小，但父母與子女仍明顯
   錯位，長水平折線仍存在。
2. **只把目前新增父母的子女向外微調（採用）**：伴侶與已建立的父母不動，
   讓新父母仍可置中於微調後的子女正上方。線條最乾淨，且只移動一位既有
   人物。
3. **對稱搬動伴侶與兩邊父母**：畫面最對稱，但會連帶搬動已完成的家庭，
   碰撞、同住框與使用者預期的風險都較高。

本設計取代既有「受阻時絕不移動子女」的窄規則，但只在下述可證明安全的
特定情境啟用；其他受阻情境仍沿用目前的父母剛性平移。

## 已確認行為

### 觸發條件

只有同時符合以下條件才嘗試彈開：

- 使用人物快捷按鈕，為目前沒有父母的該人物建立完整父母配對；
- 父母固定使用 `GenogramApp.GRID.CELL_WIDTH` 的標準間距；
- 父母置中於目前子女 X 時不安全；
- 子女有同列的最近伴侶，且造成占位的是該伴侶既有的父母配對；
- 子女向伴侶反方向移動後，不會與任何其他人物重疊；
- 新父母置中於調整後的子女時，人物位置與親子路徑都安全。

若任一條件不成立，不自動移動既有人物，直接沿用目前
`findQuickParentPairPlacement()` 的父母整組左右搜尋。

### 最小位移

位移方向固定為遠離同列伴侶。搜尋從半個系統格距開始，以 10px 為安全增量
逐步增加至一個系統格距；採用第一個安全位置，最大自動位移不得超過一格。
這可處理一格距伴侶加上兩組一格寬父母的典型衝突，同時避免半格仍碰到
10px 安全邊界時直接跳到一整格，讓人物只移動真正必要的距離。

伴侶、伴侶既有父母、其他人物與所有關係資料保持原位。新父母配對的中點
必須精確等於子女調整後的 X。

### 預覽、確認與取消

放置工作階段不立即改寫人物資料。`parent-pair` request 可攜帶一個既有人物
調整描述：人物 ID、原座標與候選座標。

- 預覽仍顯示兩位新父母的半透明 ghost 與三條中性虛線。
- 另顯示該子女在候選位置的半透明 ghost；預覽親子線連到候選 ghost，而非
  原位置，讓確認前畫面與提交結果一致。
- 原人物保留在原位，清楚表達這是尚未提交的移動。
- 取消或按 Esc 不修改人物座標，也不新增 history。
- 確認時先 `saveState()` 一次，再移動該子女並建立兩位父母與三條關係；整個
  操作只形成一筆 Undo，Undo 必須同時移除新父母並還原子女位置。

父母配對仍維持既有固定自動位置；pointer move、確認點擊與 Alt 都不能改寫
系統算好的父母或子女候選座標。

## 程式邊界

- 放置判斷留在 `GenogramApp`，不把人物位置政策放進
  `FamilyRoutePlanner`。
- `FamilyRoutePlanner` 繼續只負責純幾何與障礙判定。
- 人物只修改既有物件的 `x`；`personMap` 仍指向同一物件，不新增線性
  `this.persons.find(...)`。
- 親子關係仍由父母 `fromPersonId` 指向子女 `toPersonId`，不從座標推論方向。
- 不修改 JSON schema、臨床符號、關係線顏色、虛線型式或匯出語意。
- 同住框與生活圈仍依成員座標重算；因提交前只存一次 history，Undo 可還原
  其視覺範圍。
- 根目錄、`geno/`、`refactor/app/` 的 JavaScript 副本必須維持 raw MD5
  一致。

## 測試與驗收

先在 `refactor/verify_placement.js` 建立與截圖相同的失敗 fixture，再修改正式
程式：

1. 兩位伴侶相距一格，右側人物已有置中的父母；為左側人物建立父母時，
   預覽應把左側人物向左移動最小安全距離。
2. 伴侶及其既有父母座標在預覽、提交與 Undo 前後都不得被意外改寫。
3. 新父母間距等於 `CELL_WIDTH`，中點等於調整後子女 X；兩組正式親子主幹
   都從各自婚姻線中央向下，不再從內側父母旁邊產生大 L 形。
4. 取消預覽時人物、關係與 history 完全不變。
5. 提交只增加一筆 history；一次 Undo 同時還原子女位置並移除新父母與關係。
6. 清楚位置、沒有伴侶、阻擋者不是伴侶父母、半格至一格都不安全等情境，
   不得自動移動子女，仍採既有父母平移 fallback。
7. 預覽仍只有既有中性虛線語意，不套用正式臨床線色；正式 draw、hit-test、
   PNG/JPEG/SVG/PDF 匯出繼續共用家庭路徑。
8. 完成後執行 placement、家庭路由、拖曳、round-trip、視覺 smoke、Golden、
   三副本與離線部署守門，全部通過才能交付。

## 不在本次範圍

- 不重排整個世代或整個家族。
- 不對一般手動拖曳加入新的自動彈開。
- 不移動伴侶、伴侶既有父母或其他既有人物。
- 不改焦點模式、語意縮放、minimap 或其他 View 功能。
