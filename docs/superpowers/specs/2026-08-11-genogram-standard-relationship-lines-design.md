# 標準家系圖婚姻線與文字避讓設計

日期：2026-08-11
狀態：使用者已確認方向，待規格檔審閱後實作

## 目標

讓婚姻／伴侶線符合臨床家系圖的視覺語意，同時避免姓名與備註蓋住關係線。
預設畫面應讓人先讀到「誰和誰是伴侶」，再讀到子女與其他親屬結構；關係線不得
因為避讓文字而變成看似家庭主幹的長 U 形。

## 非目標

- 不改 Person 座標、資料 schema、history／Undo、臨床符號、顏色、線型或虛線間距。
- 不自動重排使用者已放置的人物。
- 不把文字避讓結果寫入 `getState()` 或匯出資料。

## 視覺契約

### 1. 預設自動模式（`routeMode="auto"`）

- 同列且中間沒有符號阻擋時，關係線使用兩個人物的左右側接點，保持單一水平線。
- 子女家庭線的來源固定取該關係線真正的水平掛接段中點，不從人物 Y 座標或
  舊的 `archBarY` 推算。
- 若端點姓名／備註與關係線或日期文字重疊，先移動端點文字整塊；不得為了
  一般文字碰撞把整段關係線改成底部 U 形。

### 2. 有中間人物阻擋時

- 自動模式優先使用「上方橋接」候選：兩端仍與人物保持清楚的關係連結，橋段
  位於目前人物列上方，且不得穿過文字區塊。
- 候選必須同時計算人物符號、姓名／備註、已存在的婚姻線與家庭主幹交叉；以
  固定有限候選及確定性排序選出結果。
- 若所有候選都不安全，保留最佳確定性結果並只在編輯器顯示警示；匯出不顯示
  警示。不得靜默產生看似另一條親子主幹的長底部迴路。

### 3. 明確手動模式

- `routeMode="straight"`：保留使用者指定的直線／跨列正交幾何；只做文字整塊
  側移。
- `routeMode="over"`：明確要求上方橋接，使用上方候選。
- `routeMode="under"`：明確要求下繞，才允許底部側移／下繞候選；此模式在
  UI 上標示為進階手動選項。

## 文字排版規則

- `getPersonLabelGeometry()` 是繪製、避障、內容邊界與匯出的唯一文字幾何來源。
- 姓名與備註視為一個不可拆開的 label block；移動時整塊移動，姓名與備註行距
  保持一致。
- 預設仍放在人物下方；若與標準關係線衝突，依固定順序嘗試上方、左側、右側，
  並保留 7 世界座標 px 安全距離。
- 選擇結果只存在衍生 cache，不污染 Person JSON、Undo snapshot 或匯出 schema。

## 幾何與資料流

1. `prepareDerivedGeometry()` 先計算 label placements。
2. `getMarriageRoute()` 建立並 cache 唯一的關係線 points、decoration 與
   `attachmentSegment`。
3. 螢幕繪製、選取高亮、hit-test、日期、家庭來源、bounds 與匯出全部讀同一份
   canonical route。
4. `FamilyRoutePlanner` 使用 `attachmentSegment` 的實際水平段作為雙親家庭線
   掛接依據。
5. route cache 失效只由座標、文字、字型、關係端點／類型／route mode 等衍生輸入
   觸發；不改持久化狀態。

## 驗收條件

- 15-maximal、16-multifamily：自動婚姻線不再出現長底部 U 形；文字不被線穿過；
  子女線掛在婚姻線實際中點，且不會與上代家庭主幹產生未標示的語意混線。
- 17-label-routing：同時覆蓋 auto、over、under、straight；只有 under 明確
  使用底部下繞；straight 的線型與端點幾何保持不變。
- 連續重繪、切換 view options、PNG／JPEG 匯出與 hit-test 的 route JSON 完全一致。
- 非相關既有 golden fixtures 不得改變；任何 15／16／17 的新畫面必須先人工確認，
  才能更新 baseline。
- 所有關係、家庭、標籤、匯出、mirror sync 與 smoke gates 維持綠燈，且零
  page／console error。

## 風險與取捨

- 上方橋接可能與祖先家庭線交叉；因此候選評分必須把家庭／婚姻既有線納入，而不
  能只看人物文字。若無安全候選，編輯器警示比產生不易解讀的底部迴路更可控。
- 文字移到人物上方會改變內容邊界，但不改人物座標；bounds 與匯出必須共用同一份
  label geometry。
- 舊版 15／16 golden 代表舊的穿線／錯誤避讓結果，不自動接受為新標準；更新前
  必須重新檢查畫面語意。
